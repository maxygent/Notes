# 技巧

### 上取整

```cpp
x / y            //floordiv
(x + y - 1) / y  //celldiv
```

### overloaded + visit 批量实例化

```cpp
template <typename... Fs>
struct overloaded : Fs... {
    using Fs::operator()...;
};

template <typename... Fs>
overloaded(Fs...) -> overloaded<Fs...>;

int main() {
    std::variant<std::string, int, double> a = 2.321;

    std::visit(
        overloaded{
            [&](int &val) {
                std::cout << val << std::endl;
            },
            [&](double &val) {
                std::cout << val << std::endl;
            },
            [&](auto &val) {
                std::cout << val << std::endl;
            },
        },
        a);

    return 0;
}
```

### 读取整个文件

```cpp
std::streamsize size = file.tellg(); // tell 获取 g读

file.seekg(0, std::ios::beg); // seek 设置 g读
// 读指针放回开头，开辟空间
std::string content;
content.resize(size);         //string 通常resize不了很大
file.read(&content[0], size);
```
