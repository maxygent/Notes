### 静态库与动态库

- **静态库（`.a(Linux)/.lib(Windows)`）**：在**编译链接阶段**，库的代码被**完整拷贝**到可执行文件中。最终生成一个独立的、包含所有代码的大文件。

```bash
# 1. 只编译，生成目标文件（这步你理解正确）
gcc -c add.c -o add.o
gcc -c sub.c -o sub.o
# 2. 必须执行这一步，才叫“生成了静态库”
ar rcs libmymath.a add.o sub.o
```

```bash
g++ main.cpp -L<库目录路径> -l<库名> -o app
$LD_LIBRARY_PATH  # 库路径的环境变量

```

- **动态库（`.so(Linux).dll(Windows)/`）**：在**编译链接阶段**，只记录“需要这个库”的信息，并不拷贝代码。**程序运行时**，系统才去磁盘上加载这个库文件。

```bash
g++ -fPIC -shared test.cc -o libtest.so
```
