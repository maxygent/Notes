#### leader键 ：默认是*space*
#### 跳转
- b / w ：上一个/下一个word
-  f ：输入单个字符匹配，再次按下f跳转到下一个，`shift`+f则是上一个
- s ：匹配整个字符串，有多个则会生成随机字符用于跳转
- \[ \/ \] + e ：跳转到上一个/下一个错误
- 数字 + k / j ：向上/下跳转n行
- g g ：跳转到开头
- `shift` + g ：跳转到最后
- j / k ：上下移动光标
- `ctrl` + j / k / h / l ：在面板之间移动光标
- `shift` + h / l ：切换打开的文件页，称作buffer。buffer相关操作都在`leader` + b 当中
#### 快速操作
- d w ：删除当前光标所在单词右侧部分
- d i w ：删除光标所在单词
- c w / c i w ：删除后进入插入模式
- v w / v i w ：选中
前四条中的w可以换成( " ' \[等，代表对其中部分进行操作
- y ：复制
- p ：粘贴
- u ：撤销
- `ctrl` + r ：重做(redo )
- 数字 + y y ：不加数字代表当前行，数字代表向下n行
- o ：光标下插入新行
- c c ：删除当前行并进入插入模式 

#### 文件浏览
- `leader` + e ：打开文件浏览
- `ctrl` + \/ ：打开终端
- a ：添加文件/文件夹
