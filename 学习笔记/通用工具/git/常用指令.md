
| 操作           | 命令                                                 |
| ------------ | -------------------------------------------------- |
| 配置用户名        | `git config --global user.name "Name"`             |
| 配置邮箱         | `git config --global user.email "you@example.com"` |
| 查看配置         | `git config --list`                                |
| 初始化仓库        | `git init`                                         |
| 克隆仓库         | `git clone <url>`                                  |
| 查看状态         | `git status`                                       |
| 添加单个文件       | `git add <file>`                                   |
| 添加所有改动       | `git add .`                                        |
| 交互式添加        | `git add -p`                                       |
| 提交           | `git commit -m "msg"`                              |
| 跳过暂存提交       | `git commit -am "msg"`                             |
| 修改最近提交       | `git commit --amend`                               |
| 查看历史         | `git log`                                          |
| 单行历史         | `git log --oneline`                                |
| 图形化历史        | `git log --graph --oneline --all`                  |
| 查看某文件历史      | `git log -p <file>`                                |
| 查看某次提交       | `git show <commit>`                                |
| 工作区 vs 暂存区   | `git diff`                                         |
| 暂存区 vs 最近提交  | `git diff --staged`                                |
| 工作区 vs 最近提交  | `git diff HEAD`                                    |
| 逐行追责         | `git blame <file>`                                 |
| 列出本地分支       | `git branch`                                       |
| 列出所有分支       | `git branch -a`                                    |
| 创建分支         | `git branch <name>`                                |
| 删除分支         | `git branch -d <name>`                             |
| 强制删除分支       | `git branch -D <name>`                             |
| 重命名分支        | `git branch -m <old> <new>`                        |
| 切换分支         | `git switch <name>`                                |
| 创建并切换        | `git switch -c <name>`                             |
| 切回上个分支       | `git switch -`                                     |
| 合并分支         | `git merge <branch>`                               |
| 禁用快进合并       | `git merge --no-ff <branch>`                       |
| 放弃合并         | `git merge --abort`                                |
| 变基           | `git rebase <branch>`                              |
| 交互式变基        | `git rebase -i HEAD~3`                             |
| 继续变基         | `git rebase --continue`                            |
| 放弃变基         | `git rebase --abort`                               |
| 查看远程         | `git remote -v`                                    |
| 添加远程         | `git remote add <name> <url>`                      |
| 删除远程         | `git remote remove <name>`                         |
| 修改远程地址       | `git remote set-url <name> <url>`                  |
| 拉取不合并        | `git fetch`                                        |
| 拉取并清理        | `git fetch --prune`                                |
| 拉取并合并        | `git pull`                                         |
| 拉取并变基        | `git pull --rebase`                                |
| 推送           | `git push`                                         |
| 推送并设上游       | `git push -u origin <branch>`                      |
| 删除远程分支       | `git push origin --delete <branch>`                |
| 推送所有标签       | `git push --tags`                                  |
| 丢弃工作区改动      | `git restore <file>`                               |
| 取消暂存         | `git restore --staged <file>`                      |
| 撤销提交保留改动     | `git reset --soft HEAD~1`                          |
| 撤销提交丢弃改动     | `git reset --hard HEAD~1`                          |
| 反向提交         | `git revert <commit>`                              |
| 恢复文件到某版本     | `git checkout <commit> -- <file>`                  |
| 暂存现场         | `git stash`                                        |
| 含未跟踪暂存       | `git stash -u`                                     |
| 查看 stash     | `git stash list`                                   |
| 恢复并删除 stash  | `git stash pop`                                    |
| 恢复保留 stash   | `git stash apply`                                  |
| 删除最近 stash   | `git stash drop`                                   |
| 清空 stash     | `git stash clear`                                  |
| 列出标签         | `git tag`                                          |
| 创建轻量标签       | `git tag <name>`                                   |
| 创建附注标签       | `git tag -a <name> -m "msg"`                       |
| 删除本地标签       | `git tag -d <name>`                                |
| 推送单个标签       | `git push origin <tag>`                            |
| 删除远程标签       | `git push origin --delete <tag>`                   |
| 应用某提交        | `git cherry-pick <commit>`                         |
| 删除未跟踪文件      | `git clean -fd`                                    |
| 预览清理         | `git clean -n`                                     |
| 查看 HEAD 移动记录 | `git reflog`                                       |
| 仓库内搜索        | `git grep "text"`                                  |
| 导出快照         | `git archive --format=zip HEAD > out.zip`          |
