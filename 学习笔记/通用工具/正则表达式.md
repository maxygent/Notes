| 正则 |                含义                 |
|:----:|:-----------------------------------:|
|  .   |              任意字符               |
|  ^   |     表达式开头在[]内则表示取反      |
|  $   |              匹配整行               |
|  []  | 集合,匹配一个范围中的值[a-z]表示a-z |
|  \d  |                数字                 |
|  \D  |               非数字                |
|  \w  |         字母、数字、下划线          |
|  \W  |                非\w                 |
|  \s  |                空白                 |
|  \S  |               非空白                |
|  ()  |    分组，比如(ab)?表示?作用于ab     |
|  \|  |                 或                  |
|  \\  |         转义，表示特殊字符          |
|  \b  |              单词边界               |



| 正则  |    次数    |
|:-----:|:----------:|
|   *   |   任意次   |
|   +   | 一次或多次 |
|   ?   | 零次或一次 |
|  {n}  |  恰好n次   |
| {n,}  |  至少n次   |
| {n,m} |   n到m次   |


### 常用组合

- `.*`和`.*?`：
```txt
R---rR---r
```
对于`R.*r`会匹配成一块
而`R.*?r`会匹配成两块
- `^.*$`：匹配整行
- `^$`：匹配空行
- `^\s*$`：匹配只有空白的行(\s是空白)
- `\d+(\.\d+)?`：匹配整数或者小数
### 替换
对于:
```txt
123 abc
456 rmp
```
使用`(\d+) (\w+)`查找
并使用`$2 $1`替换可以实现交换顺序
